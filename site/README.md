# 공학수학2 중간고사 대비 학습 사이트

강의안(sec11.5–14.9), 조교 연습문제(Week 1–9), 퀴즈를 바탕으로 만든 **단일 페이지 학습 사이트**입니다.

## 여는 방법
- `site/index.html` 파일을 브라우저로 열면 바로 사용할 수 있어요.
- 수식은 인터넷이 연결되어 있으면 MathJax로 예쁘게 렌더링됩니다. (오프라인이면 LaTeX 원문으로 보일 수 있습니다.)

## 구성
- **홈** — 전체 안내
- **섹션별 정리** — 12개 섹션의 핵심 공식 + 예제(연습문제·퀴즈 기반), 각 문제는 *풀이 보기* 토글
  - 11.5 직선·평면 / 11.6 이차곡면 / 12.1–12.3 벡터함수·곡률 / 13.1–13.8 다변수 미분·극값·라그랑주 / 14.1–14.9 다중적분
- **모의고사** — 3회분, 각 회차 **단답 10문제(2점) + 서술형 3문제(10점)**
  - 90분 타이머, 단답 자동 채점(정답=초록/오답=빨강), 서술형 모범답안 토글
- **학습 가이드** — 출제 포인트 · 실수 체크리스트 · 추천 학습 순서

## 파일
| 파일 | 설명 |
|------|------|
| `index.html` | 레이아웃·스타일 |
| `data.js` | 섹션 정리/예제/모의고사 데이터 |
| `app.js` | 탭·토글·타이머·채점 로직 |

> 모의고사 문항은 퀴즈/연습문제를 변형·재구성한 **예상 문제**입니다. 수치 답은 스크립트로 교차검증했습니다.
